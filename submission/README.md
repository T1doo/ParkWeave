## 制作顺序

1. 审阅执行计划，确定统一产品与案例底稿，展开产品书内容及三分钟叙事。
2. 依已认可的视觉方向准备真实截图、AI 页面图与场景图，逐轮审阅定稿。
3. 编制 180 秒逐秒台本及逐镜 H3 提示词，完成参考图绑定检查和静态配音预演，再交给用户生成视频。
4. 按官方 Word 模板排版，将代表图、案例结果及视频二维码编入文档，导出单个 PDF 放进 05。
