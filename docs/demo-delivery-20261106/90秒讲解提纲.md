# 90 秒产品理念视频提纲

以下时间仅是剪辑建议。画面展示合成案例与本地交互，不宣称真实模型、外部预约或实际效率成效。

| 时间 | 建议画面 | 旁白参考 |
| --- | --- | --- |
| 0–10 秒 | 品牌与理念图 | 园区企业提出一个活动需求，往往要在材料、场地、设备和执行人员之间反复协调。园合希望让服务围绕同一个目标协同。 |
| 10–22 秒 | 目标输入 | 企业先说清楚要办什么，以及时间、人数和预算。园合以统一的工作空间承接这次服务诉求。 |
| 22–34 秒 | 方案、资料核对 | 面向正式产品，AI 将从受信服务目录中组织步骤与责任；人工确认和确定性校验保留在执行环节。本次用预设场景呈现这条交互路线。 |
| 34–47 秒 | 资源与冲突 | 资源不是点选后就默认可用。演示会检查容量、数量与参考预算，条件不满足时提示调整，而不是把预览写成预约成功。 |
| 47–62 秒 | 派单与接单 | 确认方案和组合后，园区专员派单，执行人员接单。任务说明、资源条件和责任角色关联到同一事项。 |
| 62–74 秒 | 回执与企业确认 | 执行回执到达后，由企业明确核对结果。发送、接单、回执和确认，分别保留自己的状态。 |
| 74–84 秒 | 档案与输出成果 | 方案、材料来源和协同事件汇总为事项档案，并能导出可阅读的方案与结构化记录。 |
| 84–90 秒 | 理念图或结束页 | 园合的理念，是把目标、约束、责任和结果连接起来，让园区企业服务更有秩序、可协同、可追溯。 |

## 文档中可使用的项目概括

园合 ParkWeave 面向产业园区的企业服务协同场景，以“企业表达目标、园区组织交付”为产品主线。设计上将目标输入、受信服务目录、方案确认、资料来源、资源条件、角色分工与结果留痕连接到同一事项，避免将一次模型输出、资源预览或消息发送等同于服务完成。

当前交付为 Windows 独立窗口中的合成案例交互演示，方案由预设模板驱动。它验证和展示的是产品交互路径及本地演示约束逻辑；真实模型规划、正式园区来源、外部预约、实际履约和完整生产验收仍需后续工程与实机证据。
