# 园合 ParkWeave · 演示交付

这份交付优先服务于视频与申报材料：提供独立 Windows 演示软件、连贯案例、页面截图和可阅读的输出样例。前端沿用蓝白淡紫、受控磨砂和实色正文。

## 怎么开始

1. 解压交付 ZIP，进入“软件”，双击 **ParkWeave演示版.exe**。请保留同目录 DLL、图标和 Web 文件夹。
2. 普通使用不需要打开浏览器、终端、Python 或数据库。软件默认最大化，适合录屏；也可以还原并缩放窗口。
3. 录制前点击左下角“重新开始案例”。它只重置本地演示进度，不删除已导出的文件。
4. 按“录制操作路线.md”走一遍，即可从目标输入到演示归档和导出。

本机前提：Windows 10/11 x64、.NET Framework 4.8、Microsoft WebView2 Runtime。当前电脑已经完成独立窗口的实际运行验证；其他电脑尚未逐机验证。

## 素材内容

- **10 张软件截图**：来自独立 EXE 内的 WebView2 实际渲染，统一 1440×900；使用明确的预设合成演示状态。
- **交互操作参考录屏**：实际浏览器交互驱动同一演示页面，包含校验、冲突和角色流转；无声 WebM，作为操作参考，不是正式参赛成片。
- **案例成果页长图**：实际下载的 HTML 成果文件渲染，适合展示输出。
- **产品理念图**：设计路线示意，不伪装成后台执行证据。
- **5 种输出文件**：办理方案、材料清单、资源组合、办理记录、案例成果 HTML。
- **第二案例对照**：20 人培训采用 B 会议室与设备的演示推荐，参考金额 900 元；主案例 40 人交流活动为 A 厅与设备，参考金额 1,500 元。
