ParkWeave / 合成只读前端验收候选（不是完整产品或Windows安装包）

前提：现有Python 3.12或更新版本的标准库、已有受支持浏览器。不自动下载/安装任何软件。
Windows操作只由已指定协调任务执行，全部程序与输出保持在用户指定E:\Software下的独立目录。
先核ZIP外部SHA256和preview-manifest.json；完整文件内容在启动前再次核对。

在解压后的新目录，用已经核实的Python绝对路径运行：
  <现有Python绝对路径> -I -B serve.py --seconds 600 --catalog-state READY
手动打开打印的127.0.0.1地址。不要更改安全设置，不自动打开浏览器，不安装服务或创建数据库。
服务仅绑定127.0.0.1，默认10分钟结束，最多允许30分钟；Ctrl+C正常结束本服务。
其他目录状态可明确改用EMPTY、ERROR、DENIED，每次均是新只读回放，不能视为业务结果。

入口上方始终说明合成/只读范围。下框呈现清单中原HTML字节，代码/样式没有注入或替换。
请只输入公开回放标识SYNTHETIC_VIEW_REPLAY_NO_AUTHORITY，不填写真实密码或令牌。
完整工作台：切资源，点原“查看有权使用的合成资源”。原GET处理器读公开历史合成DTO。
可看主题A/B、密度、长中文资源、目录空/错/拒绝反馈，日期网格和头部Esc返回原按钮。
日期与目录固定为2026-10-26历史虚构数据，不表示当前资源可用、权限或预约。
所有POST/PUT/PATCH/DELETE均拒绝，未知GET拒绝，没有代理/转发或模型请求。
精简材料页仅能验登录外壳；本候选不模拟登录，不证明四角色、材料、采用、恢复或数据库业务。
本候选不含Python解释器、PostgreSQL、WebView2、Windows EXE或任何真实账户/数据库。

浏览器验收仍需记录实际系统/浏览器、源码SHA、iframe真实内容视口、缩放与输入方式。
建议先1366×768和1440×900内容视口，再320 CSS px/200%、键盘、主题、高对比和减少动态。
外框包含范围标识；iframe高度起点768，实际宽高须测量，不能把外层窗口尺寸当页面尺寸。
本候选生成/HTTP测试不等于浏览器像素、Windows原生或产品验收通过。
