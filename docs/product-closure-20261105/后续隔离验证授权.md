# 后续隔离验证授权

用户在批准 r8 单次验证后进一步明确：“我都允许，你别再问我了”。因此同一任务、同一既定范围内的后续修复、冻结、打包和隔离验证按持续授权执行，不再逐次请求相同许可。

范围继续限定为现有临时分支、合成数据、GitHub Actions 隔离 Windows；每次整次最多 25 分钟，精确源码/产物绑定和首次尝试限制保留。不改 main、不发布或部署、不接真实数据、不调用真实模型密钥、不在用户日常电脑上执行原隔离方案的服务身份操作。

失败先读取实际结果并定位，再以具体代码或诊断变更制作新的冻结候选；不盲目重复相同失败，不把 mock、截图或构建成功当作真实办理通过。既有单次记录仍按各次 run number、源码和哈希分别登记。

这条用户更新取代早期文档中“每次后续运行均需再次明确答复”的流程要求，不改变业务/数据/身份保护和验收标准。若出现超出该范围的具体动作，另按实际范围处理。
