产品 §5.3 已允许平台内准备、材料目录与文字草稿；它不要求为了证明有价值而伪造外部机构受理。可接受的准备交付应回答用户实际要准备什么：每条当前服务条件对应的来源、已提供证据、缺失或冲突资料及下一步，采用原三值逻辑，未知不转为通过、不符合或审批结论。目录/草稿保留材料事实来源与版本，缺财务数值、资质、证明、签章时明确留缺口，不补造。用户能够据此提交、核对或补正材料，才是材料准备成果；一份只含接单/租约 ID 和一致性检查的报告不满足这个业务目的。
