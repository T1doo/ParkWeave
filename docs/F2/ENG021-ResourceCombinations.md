# ENG021 两资源本地合成组合确认

实施前范围，基线3e146a56e596d9c07e36c6ca49138be468fb5cad/干净树。依据原V1产品§5.4/7.4、F2-T03及AT09—11：本地必需资源全部确认或全不提交；按稳定顺序锁定、重验授权/版本/容量/DB期限；无外部原子性或真实预约。未改原设计/验收规格。

最小组合仅两条本人、同park/org、不同资源的有效HELD；请求显式绑定各hold_id及expected_revision，顺序不改变组合指纹，保留各自固定区间/数量/缓冲/期限。不自创必须同窗或资源优先级，不自动替代。principal共享授权锁→actor请求key→resource UUID字典序锁→记录锁；全部资源锁后一次DB clock_timestamp，各资源READ/HOLD+coreREAD/EXECUTE重验，版本同时匹配原占位和登记，启用/LOCAL_AUTHORITY/SYNTHETIC/开放/峰值容量重验，排除自身。

成功：两条HELD→CONFIRMED、组合身份/成员和不可变回执同事务。失败：无组合/新回执/部分确认，原占位仍HELD或依原TTL自然EXPIRED，UI说明原占位尚未取消。成功后TTL仅历史，单条不再可确认/释放，需显式整组取消，两条及组状态/取消回执同事务，任一当前撤权拒绝整组操作。取消不回滚服务/线下事实；只释放本地合成容量。既有单资源路径保留。当前READ/HOLD先于幂等回放，返回原回执+当前组/成员状态；取消后回放确认不重新占用。不同动作/输入同key冲突，单资源与组合共享actor/key语义。登记/授权仍只读，成员/回执不可改，组只UPDATE state；无扩大既有角色权限。

schema12新增组合/成员/回执；独立显式combination-fixtures增加第二个假资源，不改旧resource-fixtures目录。UI在本人占位列表明确选两资源后组合确认、查看整组/整组取消，保留当前视觉及合成标签。不是通用ServicePlan/Approval编排。
