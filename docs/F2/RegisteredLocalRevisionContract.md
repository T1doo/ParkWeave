actor/key 幂等指纹先核对权限再恢复；同 key 不同 body/Case 拒绝，独立 key 并发 CAS 只有一次成功。原恢复入口只读证明后续 ADOPT 事件（同 plan、revision+1）；原 11 字段、640 字节、8 槽、24 小时句柄无需保存正文、源 hash、令牌或增加字段。丢响应冷开只 GET，不自动重发；迟到响应、身份/Case 切换、403 私有清除沿用原隔离。
