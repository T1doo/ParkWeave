A zero-width regex lookahead examines every possible starting position, including positions inside a longer URL-safe word; membership in the complete private-value set identifies the original full-match intervals. Matches are ordered by position. If any known intervals overlap, the entire text call falls back to the caller's original ordered `.count`/`.replace` algorithm.
