## 下载、启动与清理

先按 `SHA256SUMS.txt` 核对文件。源码/wheel 面向开发集成，轮子不会自动安装数据库或配置身份。Windows 静态候选只解压到自有新临时目录检查；双击入口校验后提供明确的新建、重开、只读状态选择；新建仍因 OWNER 暂停拒绝，重开仍受独立 fixed-journal/loader 验收门约束。当前不代表可运行的 Windows 安装包。未获原生许可时不要尝试绕开入口。结束后仅删除自己新建的解压目录；不要清理未知进程或既有数据库。

包内依赖的许可与版权原件、固定资产 URL/大小/hash 位于 `runtime-assets.json` 及对应许可文件。当前资产锁和 manifest 是完整性边界，不是发布者签名，也不能证明全部 DLL 已在真实 Windows 成功加载。预发布不部署线上服务、不包含真实模型调用、生产数据或凭据。
